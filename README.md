# 五大煉化一體化流程圖

浙石化（榮盛）、恆力、盛虹、裕龍、華錦阿美五家煉化一體化廠的工藝流程圖和對比頁。兩個文件都是單獨的 HTML，直接用瀏覽器打開即可。

- `refinery-flows.html`：逐廠查看流程圖。滑鼠停在方塊上顯示這一步的作用、產物用途、本廠規模，以及進料和去向。
- `refinery-compare.html`：勾選任意幾家煉廠，並排比較規模、重油路線、裝置配置和下游產品。

## 數據說明

規模數字取自環評批復、公司公告和行業報導，個別裝置後來有擴能或方案調整，頁面上標「待核實」的項目未找到一致來源。兩個文件各自內嵌一份數據，修改時需要同時改。

出率按「設計產能 ÷ 原油加工能力」計算，屬於設計口徑；加工裝置標的是處理量佔原油的比例。恆力每天調整產品結構，成品油收率取 40%–50% 區間粗比；裕龍為 18%–40% 柔性設計。
